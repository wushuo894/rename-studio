# Tauri 批量重命名工具项目规划

## 1. 项目概述

### 1.1 项目名称

暂定名称：Rename Studio

### 1.2 项目目标

开发一款跨平台桌面批量重命名工具，为用户提供文件选择、规则配置、结果预览、冲突检查、批量执行和撤销功能。

项目优先支持 macOS 和 Linux，同时提供 Windows x64 构建。第一版以本地单机使用为目标，不引入账号、云端同步和数据库服务。

平台适配优先级：

1. macOS：优先完成开发、测试和安装包发布。
2. Linux：同步完成核心功能适配，并优先支持主流桌面发行版。
3. Windows：提供 x64 安装包并持续进行兼容验证。

### 1.3 目标用户

- 需要整理照片、视频、文档的普通用户
- 需要批量处理素材的设计、剪辑和摄影人员
- 需要按固定规则整理文件的开发及办公人员

## 2. 技术选型

| 模块 | 技术 | 用途 |
| --- | --- | --- |
| 桌面框架 | Tauri 2 | 窗口管理、系统能力及应用打包 |
| 前端框架 | Vue 3 | 构建用户界面 |
| UI 组件库 | Vuetify | 实现标签页、表单、按钮、表格和深色主题 |
| 业务语言 | JavaScript | 重命名规则、状态管理、文件操作编排及交互逻辑 |
| 构建工具 | Vite | 前端开发和构建 |
| 样式方案 | Vuetify + CSS | 页面布局、组件样式和细节调整 |
| 桌面能力 | Tauri 官方插件 | 文件选择、目录访问和文件重命名 |
| 原生层 | 最小化 Rust 代码 | 启动 Tauri 并注册所需插件，不承载主要业务 |
| 包管理器 | pnpm | 管理前端依赖 |
| 版本管理 | Git | 管理代码版本 |

### 2.1 语言职责

- JavaScript：管理文件列表、实现重命名规则、生成预览、检查冲突并调用 Tauri 插件执行文件操作。
- Vue：组织页面、功能组件和响应式状态。
- Vuetify：提供标签页、输入框、选择框、按钮、复选框、数据表格和对话框等界面组件。
- Tauri 插件：向 JavaScript 提供文件选择、目录读取和文件重命名能力。
- Rust：仅用于初始化 Tauri、注册插件和完成应用编译，原则上不编写业务后端。
- HTML/CSS：实现页面结构、布局和视觉效果。
- JSON：配置 Tauri、权限和应用元数据。

本项目所称的“JS 后端”是指 JavaScript 负责全部业务逻辑，并通过 Tauri 官方插件访问本地系统。Tauri 应用仍会包含少量必要的 Rust 启动代码，但不在 Rust 中实现重命名业务。

## 3. 功能范围

### 3.1 第一版核心功能

1. 文件导入
   - 通过系统对话框选择多个文件
   - 选择整个文件夹并读取其中的文件
   - 支持拖拽文件到应用窗口
   - 支持从列表中移除或清空文件

2. 查找替换
   - 输入需要查找的文本和替换后的文本
   - 支持添加多组查找替换规则
   - 可选择是否替换文件扩展名
   - 支持普通文本匹配
   - 支持正则表达式匹配
   - 查找内容为空时不给出无意义的替换结果

3. 插入内容
   - 插入固定文本
   - 插入文件在当前列表中的序号
   - 支持插入到开头、指定位置或末尾
   - 指定位置支持输入字符下标
   - 文件名与扩展名默认分开处理，避免文本被插入扩展名之后

4. 自动编号
   - 设置起始序号
   - 设置编号类型，例如阿拉伯数字、字母或其他可扩展格式
   - 设置固定编号位数并自动补零
   - 设置编号前面的字符
   - 设置编号后面的字符
   - 编号顺序跟随文件列表当前排序

5. 自定义 JavaScript
   - 提供脚本编辑器供高级用户编写文件名转换逻辑
   - 向脚本提供原文件名、基础名称、扩展名、序号及文件信息
   - 脚本返回新的基础文件名或完整文件名
   - 执行前对全部文件运行预览，不直接修改磁盘文件
   - 单个脚本执行失败时标记对应文件并显示错误信息
   - 提供示例代码和“恢复默认脚本”功能
   - 限制脚本可访问的上下文，不直接暴露 Tauri 文件系统 API

6. 实时预览
   - 同时显示原文件名和新文件名
   - 标记未发生变化的文件
   - 标记重名、非法字符和空文件名
   - 执行前显示成功项、跳过项和错误项数量

7. 批量执行
   - 用户确认后执行重命名
   - 显示每个文件的执行结果
   - 单个文件失败时继续处理其他文件
   - 输出本次任务摘要

8. 文件排序与选择
   - 默认按名称升序排列
   - 支持名称、大小、修改时间和创建时间的升序与降序
   - 支持全选、取消选择和单项选择
   - 状态栏显示当前选中的文件数量
   - 自动编号以当前显示顺序为准

9. 撤销操作
   - 保存最近一次成功操作的旧路径与新路径
   - 支持撤销最近一次批量重命名
   - 撤销前重新检查路径占用情况

### 3.2 后续版本功能

- 保存和复用规则预设
- 根据创建时间、修改时间或媒体信息命名
- 递归扫描子目录
- 文件与文件夹混合重命名
- 多步规则流水线
- 操作历史记录
- 深色主题与多语言
- 自动更新

### 3.3 暂不包含

- 云端同步与用户账号
- 在线文件管理
- 文件内容编辑
- 跨设备任务同步
- 文件格式转换

## 4. 系统架构

```text
Vue 3 用户界面
    |
    | Vuetify 组件、展示预览
    v
JavaScript 业务层
    |
    | Tauri 插件 API
    v
Dialog / FS 等 Tauri 插件
    |
    | 读取文件、执行重命名
    v
本地文件系统
```

### 4.1 前端模块

- `components/file-list`：文件列表、选择状态和错误提示
- `components/find-replace`：查找替换规则编辑器
- `components/content-insert`：固定文本和连续序号插入面板
- `components/auto-number`：自动编号配置面板
- `components/custom-script`：自定义 JavaScript 编辑器及运行错误提示
- `components/preview-table`：原名称与新名称对照预览
- `components/task-summary`：执行确认与结果统计
- `stores/rename-task`：当前文件、规则、预览和任务状态
- `services/tauri`：统一封装对 Rust 命令的调用
- `services/file-system`：封装 Tauri 文件选择和文件系统插件
- `utils/rename-rules`：纯 JavaScript 重命名规则方法
- `utils/script-runner`：控制自定义 JavaScript 的输入、输出和异常

### 4.2 Tauri 与文件系统模块

- `@tauri-apps/plugin-dialog`：打开文件和文件夹选择对话框
- `@tauri-apps/plugin-fs`：读取目录、查询文件信息及执行重命名
- Tauri capabilities：限制应用允许访问的路径和文件系统操作
- `src-tauri/src/lib.rs`：注册应用所需插件，不实现主要业务逻辑

## 5. 关键业务流程

### 5.1 预览流程

1. 用户选择文件或文件夹。
2. JavaScript 通过 Tauri 插件读取路径和文件元数据。
3. 用户选择功能标签并修改相关配置。
4. JavaScript 按当前功能计算目标文件名。
5. JavaScript 检查名称格式、列表内重复及磁盘目标冲突。
6. 页面展示预览及错误状态。

### 5.2 执行流程

1. 前端提交已确认的源路径与目标路径。
2. JavaScript 通过 Tauri 插件再次检查源文件、目标名称和权限。
3. JavaScript 生成完整的重命名计划。
4. 对名称互换或循环依赖的文件先改为唯一临时名称。
5. JavaScript 调用 Tauri 文件系统插件执行最终重命名。
6. 返回逐项结果并保存可撤销记录。

### 5.3 撤销流程

1. 读取最近一次成功任务记录。
2. 检查当前文件是否仍位于重命名后的路径。
3. 检查原路径是否已被其他文件占用。
4. 对满足条件的文件执行反向重命名。
5. 返回完整、部分或失败的撤销结果。

## 6. 安全与边界处理

- 默认不覆盖已有文件。
- 执行前再次检查磁盘中的真实状态。
- 保留扩展名时，不允许规则意外修改扩展名。
- 根据操作系统校验非法字符和保留名称。
- 正确处理 Unicode、中文名称和超长路径。
- 正确处理 macOS 文件名 Unicode 规范化差异。
- 检测目标磁盘是否区分文件名大小写，避免仅修改大小写时失败。
- 支持 Linux 文件权限、符号链接和不同桌面环境下的文件选择行为。
- 默认不跟随符号链接递归扫描，防止重复或越界处理文件。
- 名称交换时使用唯一临时文件名，防止互相覆盖。
- 文件被占用、权限不足或文件消失时返回明确错误。
- 不调用系统 Shell 命令，不拼接未经校验的命令行字符串。
- Tauri 权限限定在用户主动选择的文件范围内。
- 自定义 JavaScript 只用于计算新文件名，不允许直接执行文件操作。
- 自定义脚本需要限制运行时间，避免死循环导致界面长时间无响应。

## 7. 界面规划

主窗口参考截图采用上下分区布局，顶部通过标签页切换功能：

```text
+------------------------------------------------------+
| 查找替换 | 插入内容 | 自动编号 | 自定义 JavaScript  |
+------------------------------------------------------+
| 当前功能配置区                                       |
| 查找和替换 / 内容和位置 / 编号格式 / JS 编辑器       |
+------------------------------------------------------+
| 文件拖放与预览列表                                   |
| 原文件名 -> 新文件名，状态、冲突及错误信息            |
+------------------------------------------------------+
| 添加文件  添加文件夹  排序  已选数量    执行重命名   |
+------------------------------------------------------+
```

交互要求：

- 没有有效文件时禁用执行按钮。
- 存在冲突或非法名称时禁止直接执行。
- 功能标签或配置变化后立即刷新预览。
- 大量文件时使用虚拟列表，避免界面卡顿。
- 危险操作必须经过确认，但不重复弹出无意义提示。
- 默认使用与截图接近的深色界面，并兼顾窗口缩放后的布局。

### 7.1 查找替换界面

- 左侧为“查找”输入区域，右侧为“替换成”输入区域。
- 两个区域之间显示替换方向。
- 底部提供“替换文件扩展名”复选框。
- 提供“添加替换规则”按钮，允许按顺序执行多组替换。

### 7.2 插入内容界面

- 内容类型支持固定文本和连续序号，连续序号位数默认值为 2。
- 位置使用分段控件切换：开头、指定位置、末尾。
- 固定文本模式显示文本输入框。
- 序号模式显示编号格式选项。

### 7.3 自动编号界面

- 中间区域配置起始序号、序号类型和固定位数。
- 左侧输入编号前面的字符。
- 右侧输入编号后面的字符。
- 编号配置改变后立即按当前文件顺序生成预览。

### 7.4 自定义 JavaScript 界面

- 主体为等宽字体代码编辑区。
- 顶部提供可用变量说明和示例选择菜单。
- 底部显示脚本运行结果或错误信息。
- 提供测试运行、恢复默认和应用预览操作。

## 8. 开发阶段

### 阶段一：项目初始化

- 创建 Tauri 2、Vue 3、TypeScript 项目
- 配置代码格式化、检查工具和目录结构
- 配置 Vuetify 和深色主题
- 配置文件选择、拖拽及文件系统权限
- 建立 JavaScript 调用 Tauri 插件的基础能力

交付结果：应用可以启动，并能通过系统对话框选择文件。

### 阶段二：规则与预览

- 定义文件和规则数据模型
- 实现查找替换、插入内容和自动编号
- 实现自定义 JavaScript 计算与异常捕获
- 实现各功能模式的实时预览
- 实现非法名称和列表内重名检查

交付结果：用户可以配置规则并看到可靠的重命名预览。

### 阶段三：安全执行

- 在 JavaScript 中实现安全的重命名计划
- 处理覆盖、互换、循环和临时名称
- 通过 Tauri 文件系统插件实现批量执行和逐项结果返回
- 完善权限、占用和文件消失等错误提示

交付结果：应用可以安全完成批量重命名。

### 阶段四：撤销与体验优化

- 实现最近一次任务记录和撤销
- 增加拖拽导入、快捷操作及加载状态
- 优化大文件列表性能
- 完善空状态、确认框和结果摘要

交付结果：第一版核心使用流程完整。

### 阶段五：发布

- 配置应用名称、图标、版本和安装包信息
- 优先构建 macOS Apple Silicon 安装包，不提供 Intel 架构版本
- 配置 macOS 应用签名、公证及文件访问权限说明
- 构建 Linux 安装包，第一阶段提供 AppImage 和 deb 格式
- 在 Ubuntu 和常见 Linux 桌面环境中验证文件选择、拖拽及重命名
- Windows x64 安装包及自动发布
- 编写使用说明和发布记录
- 建立版本发布流程

交付结果：生成可安装和分发的桌面应用。

## 11. 完成标准

第一版满足以下条件即可发布：

- 可以选择或拖入多个文件。
- 支持查找替换、插入内容、自动编号和自定义 JavaScript。
- 执行前能够准确预览全部新名称。
- 能发现非法名称、重复名称和已存在的目标文件。
- 批量执行不会静默覆盖用户文件。
- 支持撤销最近一次成功的批量操作。
- 对失败项给出可理解的原因。
- 可生成 macOS、Linux 和 Windows 安装包。

## 12. 后续实施顺序

建议先完成“文件选择 -> 查找替换 -> 实时预览 -> Tauri 插件安全执行”这一条最小闭环，再依次增加插入内容、自动编号、自定义 JavaScript 和撤销。这样可以优先验证文件权限、路径处理和批量重命名安全性，这些是项目中风险最高的部分。
