# Rename Studio 项目规划

## 1. 项目概述

### 1.1 项目名称

暂定名称：Rename Studio

### 1.2 项目目标

开发一款跨平台桌面批量重命名工具，为用户提供文件选择、规则配置、结果预览、冲突检查、批量执行和撤销功能。

项目优先支持 macOS，同时支持 Linux x64 和 Windows x64。自动发布提供 macOS Apple Silicon DMG、Linux x64 归档/安装包和 Windows x64 安装程序。第一版以本地单机使用为目标，不引入账号、云端同步和数据库服务。

平台适配优先级：

1. macOS：优先完成开发、测试和安装包发布。
2. Linux：同步完成核心功能适配，发布 x64 资源内嵌二进制。
3. Windows：完成 x64 适配，发布 MyGo 安装程序和签名更新包。

### 1.3 目标用户

- 需要整理照片、视频、文档的普通用户
- 需要批量处理素材的设计、剪辑和摄影人员
- 需要按固定规则整理文件的开发及办公人员

## 2. 技术选型

| 模块 | 技术 | 用途 |
| --- | --- | --- |
| 桌面框架 | MyGo | 管理窗口、原生对话框、拖放及前后端通信 |
| 前端 | Vue 3、Vuetify、JavaScript | 管理任务、计算重命名规则和显示预览 |
| 文件操作 | Go | 文件扫描、直接重命名、回滚和撤销 |
| 构建 | Vite、pnpm、Go | 编译前端并将资源嵌入桌面二进制 |
| 版本管理 | Git | 管理代码版本 |

前端通过 `src/services/fileSystem.js` 使用桌面能力，Go 入口位于根目录 `main.go`，应用配置统一在 `mygo.json`。GitHub Actions 通过 `.github/workflows/build.yml` 构建并发布三平台产物。

## 3. 功能范围

### 3.1 第一版核心功能

1. 文件导入
   - 通过系统对话框选择多个文件
   - 支持拖拽文件或文件夹到应用窗口，最多扫描 5 层，拖入的文件夹自身算第 1 层
   - 支持从列表中移除或清空文件

2. 查找替换
   - 输入需要查找的文本和替换后的文本
   - 支持添加多组查找替换规则
   - 可选择是否替换文件扩展名
   - 支持普通文本匹配
   - 支持正则表达式匹配
   - 查找内容为空时不给出无意义的替换结果

3. 插入内容
   - 插入固定文本
   - 插入文件在当前列表中的序号
   - 支持插入到开头、指定位置或末尾
   - 指定位置支持输入字符下标
   - 文件名与扩展名默认分开处理，避免文本被插入扩展名之后

4. 自动编号
   - 设置起始序号
   - 设置编号类型，例如阿拉伯数字、字母或其他可扩展格式
   - 设置固定编号位数并自动补零
   - 设置编号前面的字符
   - 设置编号后面的字符
   - 编号顺序跟随文件列表当前排序

5. 自定义 JavaScript
   - 提供脚本编辑器供高级用户编写文件名转换逻辑
   - 向脚本提供原文件名、基础名称、扩展名、序号及文件信息
   - 脚本返回新的完整文件名
   - 执行前对全部文件运行预览，不直接修改磁盘文件
   - 单个脚本执行失败时标记对应文件并显示错误信息
   - 提供示例代码和“恢复默认脚本”功能
   - 限制脚本可访问的上下文，不直接暴露桌面桥接

6. 实时预览
   - 同时显示原文件名和新文件名
   - 标记未发生变化的文件
   - 标记重名、非法字符和空文件名
   - 执行前显示成功项、跳过项和错误项数量

7. 批量执行
   - 用户确认后执行重命名
   - 显示每个文件的执行结果
   - 发现失败立即停止，并尽力恢复已移动的文件
   - 输出本次任务摘要

8. 文件排序与选择
   - 默认按名称升序排列
   - 支持名称、大小、修改时间和创建时间的升序与降序
   - 支持全选、取消选择和单项选择
   - 状态栏显示当前选中的文件数量
   - 自动编号以当前显示顺序为准

9. 撤销操作
   - 保存最近一次成功操作的旧路径与新路径
   - 支持撤销最近一次批量重命名
   - 撤销前重新检查路径占用情况

### 3.2 后续版本功能

- 保存和复用规则预设
- 根据创建时间、修改时间或媒体信息命名
- 文件与文件夹混合重命名
- 多步规则流水线
- 操作历史记录
- 深色主题与多语言

### 3.3 暂不包含

- 云端同步与用户账号
- 在线文件管理
- 文件内容编辑
- 跨设备任务同步
- 文件格式转换

### 3.4 桌面构建与更新

已使用 MyGo CLI 管理开发热更新、资源嵌入和三平台打包。根目录 Go 模块与 Vue 前端共享 `mygo.json` 配置，版本只在该文件维护。使用独立 Ed25519 密钥和官方中文更新窗口；GitHub Actions 上传安装包、更新归档、增量包和清单后发布版本。磁盘操作期间禁止重启，撤销仍限当前会话。Linux 同时提供 deb/rpm 和适合自更新的 tar.gz，Windows 提供安装程序，macOS 提供 arm64 DMG。不增加 Intel Mac 或 ARM Linux/Windows。

## 4. 系统架构

```text
Vue 3 用户界面
    |
    | Vuetify 组件、展示预览
    v
JavaScript 业务层
    |
    | MyGo 桥接
    v
Go 桌面服务
    |
    | 读取文件、执行重命名
    v
本地文件系统
```

### 4.1 前端模块

- `components/file-list`：文件列表、选择状态和错误提示
- `components/find-replace`：查找替换规则编辑器
- `components/content-insert`：固定文本和连续序号插入面板
- `components/auto-number`：自动编号配置面板
- `components/custom-script`：自定义 JavaScript 编辑器及运行错误提示
- `components/preview-table`：原名称与新名称对照预览
- `components/task-summary`：执行确认与结果统计
- `stores/rename-task`：当前文件、规则、预览和任务状态
- `src/services/fileSystem.js`：统一封装原生文件选择、拖放和文件系统调用
- `utils/rename-rules`：纯 JavaScript 重命名规则方法
- `utils/script-runner`：控制自定义 JavaScript 的输入、输出和异常

### 4.2 桌面文件服务

- MyGo 接收原生选择对话框和拖放事件，Go 从用户选定的路径导入文件。
- 导入后登记文件 ID 和磁盘身份，执行时复核源、目录与目标。
- Go 使用各平台禁止覆盖的移动操作执行批次，并保存最近一次成功批次的撤销记录。

### 4.3 核心数据结构

```js

  id: '',
  sourcePath: '',
  originalName: '',

  error: ''

```

## 5. 关键业务流程

### 5.1 预览流程

1. 用户选择文件或文件夹。
2. Go 按用户选择或拖放的路径返回文件 ID 和元数据。
3. 用户选择功能标签并修改相关配置。
4. JavaScript 按当前功能计算目标文件名。
5. JavaScript 检查名称格式和列表内同名覆盖，Go 在执行时检查磁盘目标。
6. 页面展示预览及错误状态。

### 5.2 执行流程

1. 前端提交已确认的文件 ID 和目标文件名。
2. Go 再次检查源文件身份、目标名称和目录状态。
3. Go 生成并验证完整的重命名计划。
4. 排定直接改名顺序，遇到互换或循环依赖时在改动磁盘前报错。
5. Go 使用各平台的原生改名操作，可覆盖目标处的同名普通文件。
6. 返回逐项结果，未覆盖任何文件时保存撤销记录。

### 5.3 撤销流程

1. 读取最近一次成功任务记录。
2. 检查当前文件是否仍位于重命名后的路径。
3. 检查原路径是否已被其他文件占用。
4. 对上次成功批次按反向计划直接重命名。
5. 返回完整、部分或失败的撤销结果。

## 6. 安全与边界处理

- 正向改名允许覆盖同名普通文件，多个来源的目标相同时保留列表中最后一项。
- 执行前再次检查磁盘中的真实状态。
- 保留扩展名时，不允许规则意外修改扩展名。
- 根据操作系统校验非法字符和保留名称。
- 正确处理 Unicode、中文名称和超长路径。
- 正确处理 macOS 文件名 Unicode 规范化差异。
- 检测目标磁盘是否区分文件名大小写，避免仅修改大小写时失败。
- 支持 Linux 文件权限、符号链接和不同桌面环境下的文件选择行为。
- 默认不跟随符号链接递归扫描，防止重复或越界处理文件。
- 仅执行可按依赖顺序直接改名的批次。
- 文件被占用、权限不足或文件消失时返回明确错误。
- 不调用系统 Shell 命令，不拼接未经校验的命令行字符串。
- 桌面桥接只绑定任务所需的 Go 方法。磁盘操作仅接受已导入的文件 ID。
- 目录扫描通过文件状态识别符号链接，设有深度和项目数上限。
- 自定义 JavaScript 只用于计算新文件名，不允许直接执行文件操作。
- 自定义脚本需要限制运行时间，避免死循环导致界面长时间无响应。

## 7. 界面规划

主窗口上方编辑规则，中间的文件列表可以独立滚动。点击空白区选择文件，点击文件行切换勾选。底部提供执行操作。

```text
+------------------------------------------------------+
| 查找替换 | 插入内容 | 自动编号 | 自定义 JavaScript  |
+------------------------------------------------------+
| 当前功能配置区                                       |
| 查找和替换 / 内容和位置 / 编号格式 / JS 编辑器       |
+------------------------------------------------------+
| 重命名预览  已选数量  排序                           |
| 原文件名 -> 新文件名，状态、冲突及错误信息            |
| 点击选择文件，或拖放文件或文件夹                     |
+------------------------------------------------------+
| 待执行数量  执行重命名                               |
+------------------------------------------------------+
```

交互要求：

- 没有有效文件时禁用执行按钮。
- 非法名称会阻止执行，同名覆盖在执行确认中提示。
- 功能标签或配置变化后立即刷新预览。
- 大量文件时使用虚拟列表，避免界面卡顿。
- 危险操作必须经过确认，但不重复弹出无意义提示。
- 默认使用与截图接近的深色界面，并兼顾窗口缩放后的布局。

### 7.1 查找替换界面

- 左侧为“查找”输入区域，右侧为“替换成”输入区域。
- 两个区域之间显示替换方向。
- 底部提供“替换文件扩展名”复选框。
- 提供“添加替换规则”按钮，允许按顺序执行多组替换。

### 7.2 插入内容界面

- 内容类型支持文本、序号和文件信息。
- 位置使用分段控件切换：开头、指定位置、末尾。
- 固定文本模式显示文本输入框。
- 序号模式可设置起始序号、数字或字母、固定位数和前后缀，默认使用 2 位。
- 文件信息模式可插入创建时间、修改时间、大小、图片尺寸或拍摄时间，并支持前后缀。缺少所选信息时跳过该文件。

### 7.3 自动编号界面

- 中间区域配置起始序号、序号类型和固定位数。
- 左侧输入编号前面的字符。
- 右侧输入编号后面的字符。
- 编号配置改变后立即按当前文件顺序生成预览。

### 7.4 自定义 JavaScript 界面

- 默认显示预设选择和管理入口，选中预设后立即更新预览。
- 「管理脚本」弹窗集中处理新增、编辑和删除。保存后选中并应用该脚本，同名时提示修改名称。
- 脚本出错时直接显示错误，编辑弹窗关闭后也能看到。

## 8. 开发阶段

- 创建 MyGo、Vue 3、JavaScript 项目

- 配置 Vuetify 和深色主题
- 配置文件选择、拖拽及文件系统权限
- 建立 JavaScript 调用 MyGo 服务 的基础能力

### 阶段二：规则与预览

- 定义文件和规则数据模型
- 实现查找替换、插入内容和自动编号
- 实现自定义 JavaScript 计算与异常捕获

交付结果：用户可以配置规则并看到可靠的重命名预览。

### 阶段三：安全执行

- 在 Go 中实现安全的重命名计划
- 检查目标占用并处理直接改名的依赖顺序

交付结果：应用可以安全完成批量重命名。

### 阶段四：撤销与体验优化

- 实现最近一次任务记录和撤销

交付结果：第一版核心使用流程完整。

### 阶段五：发布

## 11. 完成标准

第一版满足以下条件即可发布：

- 可以选择或拖入多个文件。
- 支持查找替换、插入内容、自动编号和自定义 JavaScript。
- 执行前能够准确预览全部新名称。
- 能发现非法名称、重复名称和已存在的目标文件。
- 批量执行前提示同名文件会被覆盖，覆盖无法撤销。
- 支持撤销最近一次成功的批量操作。
- 对失败项给出可理解的原因。
- GitHub Actions 可生成并发布 macOS Apple Silicon DMG。
- GitHub Actions 可发布 Linux x64 和 Windows x64 资源内嵌二进制。

## 12. 后续实施顺序

建议先完成“文件选择 -> 查找替换 -> 实时预览 -> Go 文件服务安全执行”这一条最小闭环，再依次增加插入内容、自动编号、自定义 JavaScript 和撤销。这样可以优先验证文件权限、路径处理和批量重命名安全性，这些是项目中风险最高的部分。
